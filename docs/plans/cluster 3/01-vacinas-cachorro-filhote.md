## H1: Primo-Vacinação de Filhotes: Como Garantir Que Nenhuma Dose É Perdida

As primeiras semanas de vida de um cachorro ou gatinho são as mais intensas em termos de vacinação. O veterinário define o protocolo — tipicamente várias consultas num curto período, com intervalos específicos entre doses. Para o veterinário é rotina. Para o tutor — especialmente se é o primeiro animal — é fácil perder-se.

"Quando é a próxima dose?" "Já posso levá-lo à rua?" Estas perguntas enchem os telefones das clínicas. E quando o tutor se atrasa numa dose, o protocolo pode ser comprometido.

O makeit.bot agenda as consultas de vacinação desde a primeira visita e envia lembretes automáticos para cada dose. O tutor não precisa de lembrar de nada — o sistema gere a timeline completa.

---

## Porque a Primo-Vacinação É Diferente

### O desafio: várias consultas em poucas semanas

A primo-vacinação exige que o tutor volte à clínica várias vezes num curto espaço de tempo. O protocolo exacto — quais vacinas, em que idades, com que intervalos — é definido pelo veterinário com base nas guidelines actuais e na realidade do animal.

O que é universal: **se o tutor faltar a uma dose ou atrasar significativamente, a protecção pode ser insuficiente.**

O entusiasmo do tutor é alto na primeira consulta (animal novo!). Mas entre a vida, o trabalho e a confusão de datas, muitos não completam o protocolo inteiro.

## O Que o Tutor Precisa de Saber (Genérico)

Em vez de listar protocolos específicos (que variam entre veterinários e regiões), o importante que o tutor deve entender:

- **São necessárias várias doses** — uma única vacina raramente é suficiente para protecção completa
- **Os intervalos importam** — demasiado cedo ou demasiado tarde pode afectar a eficácia
- **A antirrábica é obrigatória** para cães em Portugal
- **Só o veterinário** pode determinar o protocolo correcto para cada animal
- **Completar o protocolo é essencial** — não basta "fazer uma ou duas"

O papel do makeit.bot não é definir protocolos — é garantir que o protocolo definido pelo veterinário é cumprido pelo tutor.

## Como o makeit.bot Gere a Primo-Vacinação

**1. Na primeira consulta:** O veterinário regista a vacina. O sistema calcula as datas das próximas doses com base no protocolo da clínica.

**2. Lembretes automáticos:** Antes de cada dose, o tutor recebe lembrete por WhatsApp com link para marcação.

**3. Se o tutor não marca:** Lembrete de follow-up. Se continua sem marcar, a clínica é notificada.

**4. Após a última dose:** Mensagem de parabéns + informação sobre o reforço seguinte.

**5. Informação educativa:** Junto com cada lembrete, informação relevante (definida pelo veterinário):
- Quando pode sair à rua
- Importância de completar o protocolo
- O que esperar na próxima consulta

## FAQ

**Quantas consultas de vacinação precisa um filhote?**
Depende do protocolo definido pelo veterinário — tipicamente entre 2 e 4 consultas nas primeiras semanas de vida. Consulte o seu veterinário para o plano específico do seu animal.

**O que acontece se atrasar uma dose?**
Depende do atraso e da vacina. O veterinário avalia caso a caso. O sistema de lembretes existe exactamente para evitar que isto aconteça.

**Quando posso passear o cachorro na rua?**
O veterinário indicará quando é seguro. Normalmente, após completar o protocolo de primo-vacinação.

**O sistema define o protocolo vacinal?**
Não. O protocolo é sempre definido pelo veterinário. O sistema limita-se a gerir as datas e enviar lembretes.
