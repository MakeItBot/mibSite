## H1: Lembretes Automáticos de Vacinação para a Sua Clínica

A rececionista gasta horas por semana a verificar fichas e ligar a tutores cujos animais têm vacinas a vencer. Nem sempre consegue contactar todos. Alguns não atendem. Outros prometem marcar e esquecem-se.

Os lembretes automáticos eliminam este trabalho: o sistema verifica diariamente quais animais precisam de reforço e contacta o tutor. Sem intervenção humana.

---

## Diferença: Lembretes de Vacinação vs Lembretes de Consulta

Os [lembretes de consulta](/solucoes/veterinarias/agendamento-inteligente/lembretes-automaticos/) lembram de uma marcação que já existe. Os lembretes de vacinação são **proactivos** — contactam o tutor antes de haver marcação, para que a faça.

| Lembretes de consulta | Lembretes de vacinação |
|----------------------|----------------------|
| Consulta já marcada | Sem marcação — objectivo é gerar uma |
| Antes da consulta (48h, 24h, 2h) | Antes da data de reforço (configurável) |
| Objectivo: reduzir no-show | Objectivo: gerar marcação |
| Reactivo | Proactivo |

## Como Funciona

O veterinário define o protocolo vacinal de cada animal. O sistema calcula a data do próximo reforço e envia lembretes com antecedência configurável.

Cada lembrete inclui:
- Nome do animal e tipo de reforço
- Link directo para marcação online
- Opção de contactar a clínica se tiver dúvidas

Se o tutor não responder, o sistema pode enviar follow-ups (frequência e quantidade configuráveis pela clínica).

Todos os lembretes são enviados por WhatsApp (canal principal) com SMS como fallback.

## Personalização

O veterinário pode configurar:
- **Antecedência dos lembretes** (ex: 30 dias, 7 dias antes)
- **Número de follow-ups** após vencimento
- **Mensagens por tipo de vacina** (se suportado)
- **Canal preferido** (WhatsApp, SMS, email)

## Integração com o Agendamento

Cada lembrete inclui link para o [sistema de marcação](/solucoes/veterinarias/agendamento-inteligente/). O tutor recebe, clica, marca. A consulta é criada. Os lembretes de consulta activam-se. Dois sistemas, uma cadeia sem falhas.

## FAQ

**Quanto custa enviar lembretes?**
O custo por mensagem WhatsApp ronda alguns cêntimos. Para a maioria das clínicas, o custo mensal total é uma fracção de uma única consulta de vacinação.

**O tutor pode pedir para não receber?**
Sim. É um requisito RGPD e o sistema gere opt-out automaticamente.
